## Featured projects

### [Neural Style Transfer Web App](https://github.com/tapan2003/Art-Style-Transfer)

A Streamlit application that uses a VGG19 network to combine the content of one image with the artistic style of another. Users can upload their own images, select default styles, adjust generation parameters, and download the result.

### [Content-Based Music Recommendation System](https://github.com/tapan2003/Music-Recommendation-System)

A recommendation system built using textual and numerical song features. It applies TF-IDF vectorization, feature scaling, and cosine similarity to find songs that are similar to a user's selection.

### [Renewable Energy Production Prediction and Analysis](https://github.com/tapan2003/Big_Data_Renewable_Energy_Prediction)

A machine-learning and analytics project for predicting solar and wind energy production from environmental factors, with exploratory analysis, visualizations, regression modeling, and a Power BI dashboard.
